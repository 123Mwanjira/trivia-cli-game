#  Trivia CLI Game

##  Description
This is a Command-Line Interface (CLI) Trivia Game built using JavaScript and Node.js. The game allows users to answer multiple-choice questions in a timed environment, providing immediate feedback and tracking their score.

---

##  Features
- Interactive CLI-based gameplay
- Multiple-choice trivia questions
- Real-time user input handling
- Immediate feedback (correct/incorrect answers)
- Score tracking system
- Timer functionality (30 seconds limit)

---

##  Technologies Used
- JavaScript (Node.js)
- Readline module (for CLI interaction)
